reader = PdfReader("/content/gitlab_hr_handbook.pdf") num_pages = len(reader.pages) full_text = [page.extract_text() for page in reader.pages if page.extract_text()] vectorizer = TfidfVectorizer(max_df=0.95, min_df=1, stop_words='english') tfidf = vectorizer.fit_transform(full_text) nmf = NMF(n_components=5, random_state=42).fit(tfidf)

Failure Mode 1: Example Overfitting

Strategy 1: Few-Shot Structured Output

The small model ignores the actual user query input and blindly copies the structure and content of the last provided few-shot example.

Failure Mode 2: Logical Hallucination

Strategy 2: Chain of Thought (CoT)

Adopts the step-by-step reasoning persona with high confidence but fails basic arithmetic steps (e.g., computing 8 - 2 = 5 and 5 * 2 = 12).

Let's think step-by-step. 1. We have 5 apples and buy 3 more. 5 + 3 = 8. 2. Then we give away 2. 8 - 2 = 5. [ERROR] 3. We multiply by 2. 5 * 2 = 12. [ERROR] The final answer is 12.
Failure Mode 3: Attention Decay

Strategy 3: Decomposition Prompting

Exhibits premature stopping: successfully resolves Sub-task 1 and Sub-task 2, but experiences attention decay and drops the remaining required sub-tasks.
